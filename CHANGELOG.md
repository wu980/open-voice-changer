# Changelog

All notable changes to this project will be documented in this file.

This project follows a simple versioned changelog format.

## 0.1.0 - Unreleased

### Added

- Offline pitch shifting from the command line
- Desktop interface with single-file conversion
- Batch folder conversion
- Progress display and output folder opening
- Voice effect presets: `clean`, `deep`, `bright`, `robot`, `radio`
- Demo audio generation with `ovc demo`
- Conversion history with `ovc history`
- User defaults with `ovc config`
- System-player audio playback with `ovc play`
- Batch conversion error reporting
- Batch CSV reports
- Application logs
- Ruff lint configuration
- GitHub Actions CI
- Contribution guide

### Notes

- This release does not include voice models.
- This release does not include real-time microphone conversion.
- Generated audio files are ignored by Git.
